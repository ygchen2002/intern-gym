# IPO新股上市每日策略研究报告

## 1. 研究背景与目标

### 1.1 研究背景
港股新股上市初期可能存在动量、反转和流动性冲击。本研究旨在探索：
- 首日表现能否预测后续收益？
- 加入交易成本后是否仍有可交易性？
- 外部IPO/暗盘信息能否改善过滤效果？

### 1.2 研究目标
1. 复现一个日线baseline策略（首日动量策略）
2. 实现改进策略，结合成交量确认、灰市过滤和风险管理
3. 对比两种策略的表现，分析改进效果

## 3. 未来函数审查（Look-Ahead Bias Audit）

### 3.1 审查方法
对代码进行逐行审查，确保信号生成和交易执行不使用未来数据。

### 3.2 发现并修复的问题

#### 问题1：成交量确认使用了未来数据（已修复）

**原始代码（有BUG）**：
```python
# BUG: 使用了该股票全部时间的平均成交量（包括未来）
avg_volume = bars["volume"].mean()
volume_ratio = first_day_volume / avg_volume
```

**问题**：`bars` 包含该股票所有交易日的数据，`mean()` 计算的是全局平均，包括了首日之后的数据。

**修复后代码**：
```python
# 使用整个样本第一天的平均值作为基准（cross-sectional comparison）
first_day_volumes = []
for symbol, group in daily.groupby("symbol"):
    bars = group.sort_values("trade_date")
    if len(bars) >= 1:
        first_day_volumes.append(float(bars.iloc[0]["volume"]))
sample_avg_volume = np.mean(first_day_volumes)
volume_ratio = first_day_volume / sample_avg_volume
```

**说明**：修复后使用所有股票第一天的平均成交量作为基准，这是cross-sectional比较，不使用任何股票的未来数据。

### 3.3 合理使用未来数据的情况

#### 止损/止盈检查
```python
# 使用未来high/low检查止损/止盈
for _, row in path.iloc[1:].iterrows():
    if low <= stop_level:  # 使用未来的最低价
        exit_reason = "stop_loss"
```

**说明**：这是回测的标准假设，假设日内可以按止损/止盈价格成交。在实际交易中，止损/止盈订单会在开盘时挂出，触发时成交。

### 3.4 信号生成时间线

| 信号条件 | 使用的数据 | 时间点 | 是否安全 |
|----------|-----------|--------|----------|
| 首日收益 | Day1 open/close | Day1收盘后 | ✅ 安全 |
| 成交量确认 | 所有股票Day1 volume | Day1收盘后 | ✅ 安全 |
| 灰市数据 | 上市前灰市数据 | 上市前 | ✅ 安全 |
| 跳空过滤 | Day1 close vs Day2 open | Day2开盘时 | ✅ 安全 |

### 3.5 结论
- 修复前的代码存在**严重未来函数问题**（成交量计算）
- 修复后所有信号只使用当时已知信息
- 止损/止盈使用未来数据是合理的回测假设

## 4. 策略定义

### 4.1 Baseline策略：首日动量策略

**规则**:
1. 每个股票使用第一条daily bar作为day 1
2. 计算首日收益 = Day1收盘价 / Day1开盘价 - 1
3. 若首日收益 > 5%，生成做多信号
4. 入场价使用Day2开盘价
5. 持有3个交易日（或触发止损/止盈）
6. 扣除交易成本和滑点

**止损/止盈**:
- 止损: -8%
- 止盈: +20%

**假设**:
- 首日涨幅反映市场情绪
- 短期动量效应存在

### 4.2 改进策略：成交量确认 + 灰市过滤 + 风险管理

**新增规则**:
1. **成交量确认**: 首日成交量 > 整个样本平均成交量的70%（cross-sectional比较）
2. **灰市过滤**: 暗盘涨幅 > 0（正溢价）
3. **跳空过滤**: Day2开盘跳空 < 10%
4. **动态止损**: 基于首日波动率调整止损位
5. **最大持仓天数**: 5天
6. **成本约束**: 确保交易有利可图

**信号生成逻辑**:
- 条件1（必须满足）: 首日收益 > 5%
- 条件2-4（至少满足2个）: 成交量确认、灰市正溢价、跳空不过大

**假设**:
- 成交量确认信号质量（cross-sectional比较）
- 灰市正溢价反映市场认可度
- 跳空过滤追高风险
- 动态止损适应不同波动环境

## 6. 分析与讨论

### 6.1 策略优势

**Baseline策略**:
- 逻辑简单，易于理解和实现
- 基于首日动量，捕捉市场情绪
- 可复现性强
- 在样本内有正收益（9.55%）

**改进策略**:
- 多维度过滤，信号更严格
- 动态止损适应不同波动环境
- 灰市信息提供额外参考
- 最大回撤更小（-41,592 vs -63,183）

### 6.2 策略局限

1. **样本量有限**: 仅65只股票，统计显著性有待验证
2. **市场环境**: 仅覆盖2026年上半年，未经历完整牛熊周期
3. **外部数据**: 灰市数据基于模拟，实际效果需验证
4. **执行假设**: 假设可以按收盘价成交，实际可能存在流动性问题
5. **改进策略无效**: 在无未来函数的情况下，改进策略表现不如baseline

### 6.3 改进效果分析

**成交量确认**:
- 过滤掉了6个信号（从14个减少到8个）
- 但过滤后的信号质量反而下降
- 可能原因：高成交量的IPO股票并不一定表现更好

**灰市过滤**:
- 56.9%的股票有正溢价
- 但正溢价与后续表现相关性不强

**动态止损**:
- 根据波动率调整止损位
- 但止损触发频繁，导致亏损

### 6.4 风险提示

1. **过拟合风险**: 参数调优可能导致过拟合历史数据
2. **执行风险**: 实际交易可能面临滑点、流动性等问题
3. **市场风险**: 新股市场受多种因素影响，策略可能失效
4. **未来函数风险**: 必须严格审查代码，避免使用未来数据

## 7. 结论与建议

### 7.1 主要发现

1. **Baseline策略有效**: 首日动量策略在样本内有正收益（9.55%）
2. **改进策略无效**: 多维度过滤反而降低了策略表现
3. **未来函数危害严重**: 修复前的虚假收益（105.24%）误导了分析
4. **灰市数据价值有限**: 灰市溢价与后续表现相关性不强

### 7.2 策略评估

**Baseline策略**:
- 适合作为基准对照
- 在样本内有正收益，但需要样本外验证

**改进策略**:
- 当前改进方向无效
- 需要重新思考改进策略的逻辑

### 7.3 下一步建议

1. **样本外验证**: 在更长时间段和更多股票上验证baseline策略
2. **重新设计改进策略**: 当前改进方向无效，需要重新思考
3. **因子研究**: 研究哪些因子与IPO后续表现相关
4. **实盘验证**: 在模拟盘上验证策略可行性
5. **风险管理**: 加入仓位管理、组合优化等

### 7.4 经验教训

1. **未来函数是致命的**: 必须严格审查代码，确保不使用未来数据
2. **改进不一定是进步**: 更复杂的策略不一定比简单策略更好
3. **诚实报告结果**: 即使结果不好，也要诚实报告
4. **可复现性很重要**: 代码必须可以复现，结果必须可验证
